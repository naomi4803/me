# TaxTechnologist Portfolio

A responsive personal portfolio presenting a finance and tax professional with a computer programming background. The site is built with plain HTML, CSS, and JavaScript; it does not require a framework or build step.

## View the portfolio

Open `index.html` in a web browser.

## What's included

- About section describing the TaxTechnologist focus: bridging tax and technology
- Professional experience: IT Support at MMEC for nine months
- Live project links:
  - [Mngaro Empowerment](https://mngaroempowerment.ct.ws)
  - [FlyTaxTech](https://flytaxtech.xo.je)
  - [Ingia Drive](https://naomi4803.github.io/ingia_drive/)
  - [LupaLo Lamps](https://lupalolamps.gt.tc)
  - [Tech](https://naomi4803.github.io/tech/)
  - [NyumbaLink](https://naomi4803.github.io/nyumbalink/)
- Finance and tax case studies
- Skills, education, and contact information
- Responsive navigation, an FT favicon, and a copyright year set by JavaScript

## Updating the site

Edit `index.html` to change the portfolio content:

- Update project names, descriptions, and URLs in the projects section.
- Update email and phone links in the contact section.
- Add or change education, experience, and skills in their respective sections.

The page's styles and JavaScript are included in `index.html`, so no packages or dependencies need to be installed.
